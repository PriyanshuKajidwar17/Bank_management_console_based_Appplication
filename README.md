# Bank Management System

Bank Management System is a Java based console application developed to simulate basic banking operations. The application provides different roles for Admin, Bank Manager, and Customer with login authentication and basic account management features.

## Features

Admin management

Bank Manager management

Customer management

Login authentication

Account creation

Deposit money

Withdraw money

Check account balance

Customer management

## Technology Stack

Java

Core Java

Object Oriented Programming

HashMap


## How to Run

Install Java JDK.

Open the project in IntelliJ IDEA or Eclipse.

Open the main Java class.

Compile and run the application.

Follow the instructions displayed in the console.
